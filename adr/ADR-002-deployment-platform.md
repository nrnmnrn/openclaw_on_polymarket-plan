# ADR-002: 部署平台選擇

**狀態**：已採納  
**日期**：2026-04-12

---

## 決策

使用阿里雲 SAS（2核 4G RAM，Ubuntu 22.04），透過阿里雲官方 OpenClaw 一鍵鏡像部署，以 systemd daemon 管理服務生命週期。SSH 存取透過 Tailscale，不暴露公網 IP。

---

## 背景

專案定位為個人維運的策略驗證系統，需要低成本、低維護負擔的部署方式。OpenClaw 為阿里雲官方合作框架，提供一鍵鏡像可大幅降低初始設置複雜度。

---

## 規格

| 項目 | 值 |
|------|-----|
| 主機類型 | 阿里雲 SAS |
| CPU / RAM | 2核 4G |
| 作業系統 | Ubuntu 22.04 LTS |
| 儲存 | 20GB SSD |
| 部署方式 | 阿里雲官方 OpenClaw 一鍵鏡像 |
| 服務管理 | systemd（自動重啟） |
| 網路存取 | 443 開放；SSH 透過 Tailscale |
| 每月成本 | $10-15 |

---

## 被拒絕的替代方案

- **Docker Compose on VPS**：設置更複雜，沒有一鍵鏡像優勢，維護負擔較高。
- **本地機器常駐**：依賴本地網路穩定性，不適合 24/7 交易掃描。
- **AWS/GCP**：成本更高，且無 OpenClaw 官方支援的一鍵部署優勢。

---

## 安全設計

- SSH 不暴露公網，透過 Tailscale 零信任網路存取
- 敏感環境變數透過 systemd `EnvironmentFile` 管理（見 [ADR-003](ADR-003-secret-management.md)）
